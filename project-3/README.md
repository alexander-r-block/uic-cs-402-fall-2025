In this project, you will have practice with problems related to trees and dynamic programming.
The implementations will be built off of concepts we have done in class up to this point.

**Please carefully read the problem descriptions in `Firstname_Lastname_project3.cpp`. You will need to implement algorithms to solve the specified problems.**
The project includes
- `Firstname_Lastname_project3.cpp`

### Writing Your Code
This project is distributed through GitHub and you will write your code using git for version control. My advice to you is to commit early and commit often to your repository to accurately track your progress when writing your project solutions.

The included files in this project all have additional instructions in the code comments; please read them carefully! The comments also include the point breakdowns for each of the functions you will be implementing.


#### Group Work
You may work in groups of up to 3 people.
However, every student is expected to **individually submit code**.

### Testing Your Code
I encourage you to write small test cases for yourself for this project.
A few test cases are included with this project.
You can test your code by building and running the included autograder, or by copying the relevant test cases from the included test files (in `tests/testcases`).

### Submission
As with the previous projects, your submission will be via a GitHub repository.
Please be sure to change all instances of `Firstname_Lastname` with your own first and last name.

### Grading
You are given a total of 4 problems to solve in this project. Each problem is worth 25 points.

**Undergraduate Students:** You are expected to complete 3 of the 4 problems. You may choose which to complete. Extra credit (up to 10 points) will be given if you solve all 4 problems.
Note you can also reach your upper limit of 75 points by partially completing all 4 of the problems.

**Graduate Students:** You are expected to submit solutions for all problems.

#### Autograder
I will again use an autograder for this assignment. Instructions for the autograder are included. 

#### Manual Inspection
Part of your grade will also come from manual inspection of your code. This is because the auto grader cannot check if you are implementing the correct algorithms, it can only check that you pass some tests. To help make this process smooth and easy, please be sure to write legible and clear code.

#### Code Presentation
Each student is required to give a "code presentation" after submission of their project. 
Since this project is due after Finals Week, you have two options for your code presentation.

1. Recorded video presentation. You will submit with your repository a video explaining each of your solutions to the problems you solved. This recording can be done via Zoom (and then you only need to include a link that is accessible to me for viewing), or you can include a video in your repository (assuming the video is not too large for GitHub).
2. Project write-up. You will submit with your repository a `.pdf` report detailing your implementation. In this report, you must explain each of your solutions to the problems you solved, as well as include references/pictures of your code to explain your solution.

**Important**: this code presentation is individual; i.e., even if you are working in a group, you will have to present to me as an individual. This is again to make sure you actually understand what is happening in your code.

#### Extra Credit
I will also be implementing all the functions for this project. For a bit of fun, bragging rights, and extra credit, I will run each student's code against my own code and see which one performs better. Each function you implement that can beat my code will earn you 1 point of extra credit on the project (max of 4 points for this project).
